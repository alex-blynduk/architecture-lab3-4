TaskTracker — Базова заготовка UI

Сервіс TaskTracker.TaskService успішно запущено.

Повноцінний інтерфейс користувача (створення завдань, перемикання режимів Classic REST / Event-Driven RabbitMQ, перегляд сповіщень і симуляція збоїв для Jaeger) буде додано на наступному етапі.

Документація API доступна за адресою /swagger.
